# Fossil Overlay Audit — 地図の答えは、点の置き方で変わるのか？

**化石の公開データを使って、地図から得た答えをどこまで信じられるか調べる。**

化石が見つかった場所を地図に置くと、「そこにはどんな地質が広がっているか」を調べられます。でも、記録された点が少しずれたり、地図の地質区分が違ったりすると、同じ化石について別の答えが出ることがあります。

**この研究で目指すのは、地図やデータを間違いと決めつけることではありません。** 地図を使う人が「自分の結論は、座標や使用した地図を変えても成り立つか」を確かめられるようにすることです。今回の対象は化石ですが、公開された位置情報と地図を重ねて使うさまざまな研究に通じる問いです。

- **[日本で分類が変わった15件を、実際の地図上で調べる](docs/explorer.html)**（GitHub Pages公開後にブラウザで操作できます）
- **[研究全記録：使用データ・過去の実験・失敗と検証の限界](research/研究全記録_20261109.md)**
- **[先行研究への注釈を含む詳しい研究記録](research/研究経過_文献注釈付き.md)**

日本の化石コレクション4,770件／異なる座標2,484地点から研究を始め、同一座標に年代区間の重ならない記録が含まれる122地点を確認しました。1分角丸めでは、それまで別座標だった記録間に新たに同一座標となる15,464ペアが生まれ、そのうち3,848ペアでは年代区間が重なりませんでした。詳細な根拠と解釈上の留保は上記研究全記録にあります。

**公開サイトに実測値として表示するMacrostrat比較**は、別の前処理後入力集合（日本4,766コレクション）に基づきます。これは4,770件の初期抽出全体と混同しません。GSJによる実測値および地質境界距離は、まだ得られていないため掲載していません。

---

PBDB（Paleobiology Database）の化石コレクションを地質図へ照合するとき、座標を1分角に丸めると地質単元の判定がどれだけ変わるか。これを日本と米国本土で比較した記録です。

## これは何ではないか

**大発見の主張ではありません。** オープンデータの再現性と空間感度の監査です。

このリポジトリが扱うのは次の問いだけです。

- 公開されている化石データと地質図を使って、同じ照合を誰でも再現できるか
- 座標の表現精度を1分角に落としたとき、地質図から得られる判定はどれだけ変わるか
- その感度は、使う地質図のデータソースによってどう違うか

「日本の地質は危険だ」とも「化石データは信用できない」とも言っていません。測っているのは正確さではなく、**座標処理に対する判定の感度**です。元座標そのものが正しいかどうかは、このデータからは分かりません。

## 確定していること

| | 日本 | 米国本土 |
|---|---|---|
| 抽出範囲内のコレクション | 4,766 | 54,912 |
| 元座標でポリゴンに入らなかった件数 | 858 (18.0%) | 1,946 (3.5%) |
| 両方がポリゴンに入った件数（分母） | 3,862 | 52,759 |
| **地質ポリゴンが変わった件数** | **15 / 3,862 = 0.39%** | **1,965 / 52,759 = 3.72%** |
| 95%信頼区間 | 0.24–0.64% | 3.57–3.89% |
| 年代区間の端点が変わった件数 | 15 | 1,722 |
| ポリゴン面積の中央値 | 2,863 km² | 137 km² |

日本の15件は **11地点** に由来します。1地点に5件が集中しているため、15個の独立した事象として扱ってはいけません。

### GSJの結果を載せるときの条件

- 凡例記号（`symbol`）の変化は、個別ポリゴンの変化ではない
- 年代表記（`formationAge_ja`）の変化は文字列の変化であり、化石年代との整合の反転ではない
- 15件はMacrostratで変化したものだけを選んだ条件付き標本。日本全体の率として書かない
- 全国の率は、両方の座標で取得に成功した件数を分母とし、未取得件数を併記する

## 保留した主張

「日本では年代判定のずれがより深刻である」という主張は**取り下げました**。観測が11地点にとどまり、支持できません。仮説として残しますが、結論としては扱いません。

ポリゴン年代の差の中央値（約293 Ma）は、変化した15件についてポリゴンの年代境界の差を取ったものです。**化石の推定年代がその分ずれたという意味ではありません。**

## データの出所

- 化石コレクションおよび Macrostrat 地質図: Ye & Peters (2023), *Bedrock geological map predictions for Phanerozoic fossil occurrences*, Paleobiology 49(3), 394–413. Dryad 補遺 doi:10.5061/dryad.vhhmgqnxt（2022年11月版）

## 手法と、その限界

`scripts/quant_macrostrat.py` が、指定した緯度経度範囲のポリゴンを読み込み、GeoPandas の `within` で点を結合しています。

この方法は Ye & Peters (2023) の照合手続きとは異なります。彼らの照合には年代条件や近傍探索が含まれます。したがって、**858件の未マッチを「Macrostrat に記載がない858地点」と解釈することはできません。** 未マッチ件数を元論文の数値と直接比較しないでください。

なお、日本の4,766点について複数ポリゴンへの同時一致は0件でした（最大一致数1）。

## 使い方

```bash
# サイトを生成（docs/ に出力）
npm run build

# ローカルで確認
npm run serve   # http://localhost:8080
```

依存パッケージはありません。Node 18以降が必要です。

解析を最初から再現する場合は、Dryad からデータを取得したうえで:

```bash
pip install geopandas pyogrio
python scripts/quant_macrostrat.py
```

`map_data.geojson` と `fossil_collections.csv` を同じディレクトリに置いてください。米国の per-collection CSV（約13 MB）はサイズの都合で同梱していません。上記コマンドで生成されます。
